# 동선·이동거리·속도구간 정확도 개선 계획

2026-09-17 인터뷰로 확정한 요구사항과 그에 따른 설계. 구현은 단계별로 진행하며 각 단계는 검증 프로토콜 수치로 효과를 확인한다.

## 1. 인터뷰 결과

| 항목 | 결정 |
|---|---|
| 사용 환경 | 실외 정규 축구장 + 실외 풋살장 둘 다 |
| 착용 | 등 상단 조끼, 전용 포켓으로 방향 고정 가능 |
| 현재 상태 | 보행 모드 적용 후 거리 누락은 크게 개선. 1m 간격 직각 이동 같은 디테일은 못 잡음 |
| 하드웨어 | 지금 부품만 (ATGM336H, ICM-42688-P), 보드는 S3 유지 |
| 최우선 지표 | 동선 모양과 히트맵 |
| 처리 시점 | 실시간도 적당히 정확 + 사후 분석은 더 정밀 |
| 구장 등록 | 지도에서 코너 터치 + 걸어서 등록 둘 다 |
| 원본 기록 | 폰 페이지가 저장 |
| 검증 방법 | 추천 필요 → 3장 |

## 2. 오차의 원인과 대응

| 원인 | 증상 | 대응 |
|---|---|---|
| GPS 위치 노이즈 2~3m, 수신기 내부 필터 | 모서리가 둥글어지고 1m급 움직임 소실 | 위치 대신 **Doppler 속도 벡터를 적분**해 모양을 만들고 위치로는 드리프트만 보정 (2단계) |
| GPS 10Hz, 저속에서 진행방향 불안정 | 급회전·정지 직후 방향이 튐 | **자이로 요 레이트 융합**(EKF)으로 100Hz 방향 추적 (4단계) |
| 펜스·건물 반사 (풋살장) | 점프, 지그재그 | 위치 변화가 Doppler 속도와 안 맞으면 이상값으로 기각, HDOP·위성수 가중 (2단계) |
| 실시간 필터의 지연 | 코너가 늦게 꺾임 | 사후 **양방향 스무딩**(RTS)으로 지연 제거 (5단계) |
| 구장 좌표 없음 | 히트맵이 지도 위 점일 뿐 | 코너 등록 → 피치 좌표계, 구장 밖 이상값 제거, 1m 격자 커널 히트맵 (3단계) |
| 속도 흔들림 | 구간 경계에서 깜빡임, 스프린트 과다 계수 | 융합 속도 + 체류시간·히스테리시스 (5단계) |

핵심은 2단계다. 단일대역 수신기에서 위치는 m 단위로 흔들리지만 Doppler 속도는 0.1m/s 수준으로 정확하다.
속도를 적분하면 1초 구간의 상대 이동을 10cm대로 알 수 있어, 1m 직각 이동 같은 **상대적인 모양**은 살릴 수 있다.
절대 위치는 여전히 2m 안팎이므로 "지도상 정확히 그 자리"가 아니라 "모양과 비율이 맞는 동선"이 목표다.

## 3. 검증 프로토콜 (추천)

콘 6~8개와 줄자만 있으면 된다. 매 단계 적용 전후로 같은 코스를 돌고 아래 표를 채운다.

| 테스트 | 방법 | 지표 | 1차 목표 |
|---|---|---|---|
| T1 정지 | 2분 서 있기 | 위치 산포 반경, 거리 드리프트 | 드리프트 0m, 산포 2m 이내 |
| T2 직선 | 줄자로 잰 50m를 걷기·조깅·전력 질주 각 2회 | 거리 오차 %, 직선 이탈 RMS | 오차 3% 이내, 이탈 1m 이내 |
| T3 사각 루프 | 20×10m 콘 사각형 3바퀴 | 루프 닫힘 오차, 바퀴 간 편차, 코너 뭉개짐 | 닫힘 2m, 바퀴 편차 1.5m |
| T4 계단 패턴 | 1m씩 직각으로 5단 이동 (걷기) | 직각이 구분되는가, 단 길이 오차 | 5단이 식별됨 |
| T5 속도 | 30m 전력 질주를 폰 영상으로 시간 측정 | 평균속도 오차, 최고속도 | 오차 5% 이내 |
| T6 실전 | 풋살 10분 | 히트맵이 구장 안에 들어오는 비율 | 95% 이상 |

기준 장비가 없으므로 "아는 기하(콘, 줄자)"와 "반복성(바퀴 간 편차)"을 기준으로 삼는다.
폰을 같은 포켓에 넣고 GPS 로거를 돌린 기록은 참고용 비교로만 쓴다.

## 4. 구현 단계

| 단계 | 내용 | 위치 | 기대 효과 |
|---|---|---|---|
| 1 | 세션 기록·내보내기: 폰 페이지가 fix 10Hz + IMU 25Hz 원본을 저장하고 CSV/JSON으로 내보냄. 검증 프로토콜용 구간 마커 버튼 | 페이지 | 이후 모든 튜닝과 사후 분석의 토대 |
| 2 | 속도 적분 동선: 상태 [x, y, vx, vy] 칼만 필터, 측정은 GPS 위치와 Doppler 속도 벡터. 속도-위치 불일치 이상값 기각, HDOP 가중 | 펌웨어 (실시간) | 가장 큰 개선. 모양 디테일과 거리 정확도 |
| 3 | 구장 등록(지도 터치, 걸어서) + 피치 좌표 + 히트맵 탭, 구장 밖 이상값 제거, 구장별 저장 | 페이지 | 히트맵 완성 |
| 4 | IMU 융합: 부팅 시 3초 정지 캘리브레이션(자이로 영점, 장착 기울기), 요 레이트를 상태에 추가한 EKF, 정지 검출 | 펌웨어 | 급회전·저속 방향 정확도 |
| 5 | 사후 양방향 스무딩(RTS)과 속도구간·스프린트 히스테리시스, 세션 리포트 | 페이지 | 사후 분석 정밀도 |

각 단계는 독립적으로 효과가 있고, 1 → 2 → 3 순서가 최우선 지표(동선, 히트맵)에 가장 빨리 닿는다.

## 5. 전제와 한계

- 지금 부품으로는 절대 위치 2m 안팎이 한계다. 그 이하가 필요해지면 듀얼밴드 GNSS 모듈 교체가 유일한 길이다.
- IMU 융합은 장치가 포켓에서 고정된 방향으로 밀착되어 있어야 한다.
- 실내는 범위 밖이다.
